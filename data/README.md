# Data

Every file in this folder is **synthetic**, generated by `scripts/generate_data.py`
with a fixed seed (`uv run python scripts/generate_data.py` regenerates them byte for byte).

- `products.csv`: the catalogue (40 products, a few inactive).
- `customers_pii.csv`: fake customers. Names, e-mails (`@example.com`) and phone numbers
  are invented, but treat this file as **personal data** (red tier) all the same.
- `orders_2026_01.csv`: January 2026 order lines, all valid.
- `orders_2026_02_raw.csv`: February 2026 order lines as received, with invalid lines.
