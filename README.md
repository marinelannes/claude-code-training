# orders-toolkit

The orders toolkit of **Northwind Supplies**, a (fictional) online retailer of office
equipment selling in France, Germany, Spain and Belgium. It imports the monthly order
files, computes order prices and produces the monthly report.

All data in this repository is synthetic.

## Install

You need [uv](https://docs.astral.sh/uv/) and Python 3.11 or later.

```bash
uv sync
```

## Run the tests

```bash
uv run pytest
```

## Command line

```bash
# Validate a monthly order file
uv run python -m orders import data/orders_2026_02_raw.csv --month 2026-02

# Price one order of January 2026
uv run python -m orders price O-202601-0001

# Same, as JSON
uv run python -m orders price O-202601-0001 --format json
```

Prices follow the rules of `specs/pricing.md`: volume discounts, loyalty discount for gold
customers, the `WELCOME10` promo code, shipping and VAT. Prices are rounded per line.

## Monthly report

```bash
uv run python scripts/monthly_report.py
```

It writes `out/report_2026_01.csv` and prints a summary. The notebook
`notebooks/monthly_report.ipynb` does the same thing.

## Layout

- `src/orders/`: the package (models, importer, pricing, command line)
- `specs/`: business rules
- `data/`: synthetic data, regenerated by `scripts/generate_data.py`
- `tests/`: unit tests (run by default), acceptance tests, reference cases
- `labs/`: training instructions
